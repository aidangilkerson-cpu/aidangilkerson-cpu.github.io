# Aidan Gilkerson Portfolio

Static Jekyll portfolio intended for GitHub Pages from the `main` branch and
repository root. The site URL is `https://aidangilkerson-cpu.github.io` and
`baseurl` must remain empty.

- Page content: root-level Markdown files with YAML front matter.
- Shared HTML: `_layouts/` and `_includes/`.
- Styling and theme toggle: `assets/css/` and `assets/js/`.
- Local preview and GitHub Pages steps: `README.md`.
- Do not add a backend, database, framework app, or package.json.
